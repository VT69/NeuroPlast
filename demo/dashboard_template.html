Testing Brain-Inspired Mechanisms for Task-Incremental Continual Reinforcement Learning: A Controlled Ablation Study

No statistically reliable improvement in final accuracy or forgetting beyond the matched controls; one narrow effect survived, two are conditional.

We tested six brain-inspired mechanisms one at a time, each against a matched control that is not brain-inspired, in small agents that learn a sequence of tasks with the task identity given. A seventh, Transformer working memory, is inconclusive because no benchmark we tried was shown to be valid. Given the seed counts, the results rule out large effects rather than show equivalence, and only where the intervals are narrow. Every number on this page is read from the frozen results, plus one follow-up labelled post-freeze.

What we built

An agent that sees a small grid world, turns each frame into spikes, optionally remembers the last few frames, and picks an action. It learns tasks one after another. The sleep variant alternates online learning with offline phases that revisit stored experience.

Swap one part at a timeEach ablation changes one component: spiking vs ordinary (CNN) encoder, with or without Transformer memory, local learning rules on or off. All non-isolation agents are a shared trunk with a head and a task embedding per task.
Three standard baselinesRegularisation (EWC), replay (the same buffer as sleep, interleaved with online learning) and capacity isolation (one network per task), plus naive fine-tuning. The post-freeze follow-up adds LwF, which distils the network's own earlier outputs and stores no data.
Fair budgetsSame frames, seeds and learning rate across arms; replayed samples matched exactly for sleep vs replay; memory counted as parameters plus buffer.
